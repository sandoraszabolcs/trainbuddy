# TrainBuddy — context for Claude

Start by reading **`docs/DECISIONS.md`** (design decisions + verified Strava constraints)
and **`docs/STATUS.md`** (what is built, what is not, known issues). `docs/PLAN.md` is the
approved 3-day plan. Do not re-derive these decisions; they came out of a long design
interrogation with the user.

## The three things most likely to trip you up

1. **Strava exposes only the token owner's own data**, and forbids displaying one
   athlete's data to another. Other athletes are therefore **seeded rows in our own
   Postgres** (`athlete.is_seeded`). They use the same tables and the same derived-profile
   code as the real user — matching must never branch on `is_seeded`.
2. **`segments/explore` is unavailable to us since 2026-09-01** (Extended Access Tier
   only). Never write code that depends on it. `spike/main.py` uses it and is dead code.
3. **Match responses must stay coarse** (D5b): approximate area circle, pace band,
   typical distance, habitual days, persona text. Never expose routes, exact coordinates
   or activity lists for another athlete.

## Working agreements

- Python 3.12 via `uv`; the venv is `backend/.venv` (the system python is 3.8 — do not use it).
- Database runs in Docker on **port 5433**. `DATABASE_URL` must be exported for alembic,
  the seeders and the app.
- Run the API in the background via the Bash tool's background mode; a plain `&` does not
  survive the tool call, and `pkill -f uvicorn` matches the tool's own shell.
- Geo/scoring logic stays in pure functions under `app/geo/` so it unit-tests without a
  database. Anything touching PostGIS goes in `app/matching.py` or `app/strava/sync.py`.
- Use GeoAlchemy2 types for casts (`Geography(...)`, `Geometry`) — `.cast(text("geography"))`
  raises `AttributeError: 'TextClause' object has no attribute '_static_cache_key'`.
- Alembic autogenerate is filtered to our own tables, and GeoAlchemy2 creates spatial
  indexes itself — delete any autogenerated `op.create_index('idx_...')` lines.
- Model IDs come from config (`AGENT_MODEL`, `TEXT_MODEL`), never hardcoded.
